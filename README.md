# CrafterLauncher
Crafter Launcher is an open-source, beautifully designed Minecraft launcher focusing on speed and intuitive UX. Featuring native one-click Modrinth modpack installations, multi-profile offline management, and a gorgeous glassmorphic neon aesthetic, it’s the ultimate control hub for players who want a premium, high-performance desktop experience.
🌟 Key Features
Seamless One-Click Mod Installation: Explore and install popular modpacks like Fabulously Optimized, Cobblemon, and Better MC directly within the launcher via native Modrinth API support.

Modern Glassmorphism UI: Features a gorgeous, highly polished neon-dark interface designed to stay organized, beautiful, and fluid.

Offline & Premium Profile Support: Manage your custom profiles, usernames, skins, and local setups flawlessly without extra background bloat.

Integrated Hub & Statistics: Track your active gameplay hours, organize your favorite multiplayer server nodes, and stay updated with integrated news feeds instantly.
